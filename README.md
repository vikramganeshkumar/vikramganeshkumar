## 🌟 Featured Projects & Work

### 📂 [Local RAG Chatbot & Guardrail Pipeline](https://github.com/vikramganeshkumar/sirpi-ai1)
A Streamlit-based RAG application running against local Ollama models with zero external data transmission.

- **Tech Stack:** Python, Streamlit, Ollama, AI Guardrails
- **Key Features:** Built a two-model guardrail system to screen query relevance and enforce strict document-grounded answers, preventing out-of-scope hallucinations
- **Impact / Result:** Deployed locally for team-wide use to streamline secure, fast document Q&A

### 📂 [3-Band Analog Audio Equalizer](https://github.com/vikramganeshkumar)
A hardware audio signal processing system designed, simulated, and physically validated.

- **Tech Stack:** LTspice, Oscilloscope Testing, Circuit Modeling
- **Key Features:** Designed full circuit schematics in LTspice to model dynamic frequency-band filtering before hardware prototyping
- **Impact / Result:** Validated frequency responses and signal fidelity against strict specifications at each gain stage using physical oscilloscope measurement techniques
